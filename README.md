# @xb18/dsh-select-quote

[DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/guide/quickstart) 的 Web 客户端插件：在对话里**划词加批注**——把选中的原文连同你的评论一起交给模型，并让它在回答里明确指出说的是哪一段。

- **划词工具条**：选中对话区任意文本，浮出「复制 / 引用 / 笔记 / 添加到任务」；拖拽结束才出现，不挡操作
- **批注卡片**：添加后输入框内出现一张摘要卡片（可多条），**草稿里不会出现任何协议文本**
- **正文标记**：被划中的文字在原消息里留下虚线下划线 + 序号角标；点卡片里的条目会滚回那段文字
- **模型回指**：模型回答时以内联指令标出它处理的每一条批注，插件把这些指令渲染成可点击的 chip
- **对话记录**：已发送消息里的批注渲染为卡片，用户气泡只剩你打的问题
- **笔记**：一键把选区原文存进宿主（不写评论），会话内「笔记」标签页可倒序列出、删除、点回定位；设置面板另有全局笔记页，跨会话搜索

| 项 | 值 |

## 安装

### 方式一：从 npm 安装（bundle）

```bash
dsh plugin --profile web add @xb18/dsh-select-quote
dsh --profile web
```

> ⚠️ `@xb18/dsh-select-quote` 尚未发布到 npm，方式一现在会直接 404；请先用方式二，或从仓库目录安装：`dsh plugin --profile web add <本仓库绝对路径>`。另外，npm 上的旧名 `dsh-select-quote`（0.1.0 / 0.2.0）是上游早期版本，其中 0.2.0 会让 Web 渲染进程卡死、0.1.0 不含批注卡片、正文标记与模型回指，请勿安装。

### 方式二：本地 checkout 加载（`--patch`）

```bash
git clone <repo> && cd dsh-select-quote
npm install && npm run build
dsh web --patch "$PWD/dev.patch.yml"
```

打开 `http://127.0.0.1:3080`，在对话消息里划词即可看到工具条。`dev.patch.yml` 里的插件路径按本机写死（必须是绝对路径），换机器或换目录时改那一行；该文件不随 npm 包发布。

## 用法

1. 在对话区选中一段文本 → 点「添加到任务」
2. 弹出评论框，写一句想说的话（可留空，只划不评）→ `⌘/Ctrl + Enter` 确认
3. 输入框上方出现批注卡片，悬停可展开列表：逐条编辑、删除，或一键清空；点条目会跳到正文里对应的那段文字
4. 正常打字、按 Enter 发送。批注随消息一起交给模型，卡片随之消失
5. 模型回答里指向某条批注的位置，会显示成可点的 chip

只想留个记号、不想写评论时，用工具条上的一键按钮：

- **引用**：以空评论立即提交成批注，不弹评论框
- **笔记**：把选区原文存到宿主的笔记里（不产生批注、不改正文）

### 笔记

笔记是「不交给模型、只留给自己」的记号，存的是**选区原文**，没有评论、没有标题，可在三个入口回看：

1. **一键保存**：选中对话区文本 → 工具条点「笔记」→ 立即存下，不弹评论框、不改动正文。若选区没落在消息正文里，会就地提示且**不保存**。
2. **会话内「笔记」标签页**：会话顶部标签栏多出一个「笔记」页，按时间**倒序**列出本会话的全部笔记，可逐条删除；点某条会切回对话并滚回那段文字（短暂高亮）。
3. **设置页「笔记」一节**：跨会话列出所有笔记，带**搜索**（大小写不敏感，支持中文子串），显示每条所属会话，可跳转到对应会话并定位，也可删除。

笔记落盘在宿主的 `$DSH_HOME/select-quote/notes.json`（默认 `~/.dsh/select-quote/notes.json`），刷新页面、切换会话都不会丢；它是纯追加/删除的 JSON，可自行备份。

## 已知限制

- **待发批注只在内存里**：刷新页面或切换会话后会丢，卡片不持久化（已发送消息里的批注不受影响）。
- **占用了用户气泡的渲染**：本插件以最低优先级替换内置 `user` 节点。若其它插件也替换同一个键（例如 `dsh-easyrewrite` 用 `-1`），会被本插件屏蔽。
- **卡片宽度有限**：输入框内每条摘要最宽约为输入框的 1/4，超长标题走省略号。
- **笔记存在宿主侧文件里**：位置为 `$DSH_HOME/select-quote/notes.json`（默认 `~/.dsh/select-quote/notes.json`）。删除该文件等于清空全部笔记，且不会影响已发送消息里的批注。
- **笔记定位依赖目标消息已挂载**：点笔记条目要滚回正文，靠的是「消息锚点（`data-chat-node-key` / `data-chat-flow-key`）+ 消息内字符偏移」。若那条消息**尚未加载进分页窗口**（默认只含最近约 1-2 个 turn，所以较早的笔记常常落在这个窗口之外），插件会**主动调用该会话的「加载更早」把历史翻进来**（最多 12 页、总时限 12 秒），目标一出现就精确滚动并高亮。翻完仍没出现时才会明确提示「已尝试加载更早历史仍未出现原消息，请先手动向上翻页到那句话附近，再点一次」——**不会静默失败，也不会把「按文本找到的相近位置」冒充成精确命中**。
  - 说明：正文列表是直接 map 渲染的，行**不会**被虚拟滚动回收（`@tanstack/react-virtual` 仅用于右侧 turn 导航轨与 Trajectory 台账），因此定位失败的原因不是「行被回收」，而是「那段历史这一轮压根没被加载」。
  - 若当前部署根本没暴露「加载更早」能力（`sessions.binding(id)` 拿不到 `loadOlder`），就没有可翻的页，此时只等渲染（6 秒），提示语也换成「当前版本拿不到『加载更早历史』的能力」，**不会**谎称「已尝试加载更早历史」。这种情况下的文本降级同样受该 6 秒窗口约束，不再一上来就按文本宣告成功。
- 划词只在对话区生效，不介入编辑器、终端等面板。
